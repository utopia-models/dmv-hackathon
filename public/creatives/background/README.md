# /public/creatives/background — the interview background-loop clips (knowledge#2608)

`/creatives/background` plays every `.mp4`/`.webm` in **this folder**, back to back,
looping forever with zero chrome — for the second monitor during the judge interview.

> **Drop a clip here and it plays. No code edit, no manifest.** Files play in
> alphabetical order (prefix `01-`, `02-`… to control order).

This is where the **knowledge#2606** `scenario-<v0|doctor|lawyer|kid>-<n>.mp4` clips
go once they are pulled out of Drive (`DECK-ready/background-pitch-video`).

**Until a clip lands here**, the route falls back to the four real scenario clips
already committed to the deck (`/slides/lineup-{v0,doctor,lawyer,kid}.mp4`) — one per
RAW scenario — so the loop is never empty and never a placeholder.

- Supported: `.mp4`, `.webm`.
- `README.md` and dotfiles are ignored.
